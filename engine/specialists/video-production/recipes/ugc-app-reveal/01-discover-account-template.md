# Account and template discovery

Use the separate JSON inputs named {run_context}, {source_facts}, {brand_voice},
{story}, {approved_scope}, {asset_inventory}, {provider_plan} and {review_schedule}.
Keep this markdown intact when an orchestration adapter supplies those objects.

Read the current product and accepted direction. Inventory reusable media before
requesting any generation. Inspect the selected account's relevant workflow
catalog through the operator's authorized tools. Record discovery, attachment,
invocation, authentication and returned output as separate observations.

When native ChatCut Agent mode is selected, the workflow must be attached and that
surface invoked. External MCP orchestration must be named as such. Reading a
workflow does not run its web agent. Preserve the current project and its accepted
assets where they fit the request.

Inspect the named animation template's real source. Record its URL, revision or
hash, entry file, license, retained components and authorized layout changes.
For AI Chat Reveal, inspect the current source and carry its applicable terms;
do not rely on a remembered version or a screenshot alone. Report missing template
or materializer files and identify the source used instead.

Separate generation, enhancement, authored UI, final editing and speech providers.
Use the actual returned creator, model and gateway for each operation. Account
access does not establish a paid balance, a quote or permission for another job.
Check only the capabilities required by the chosen route.

Return a discovery report, reusable-source inventory, source-attribution record,
remaining inputs and proposed next stage. A specialist can prepare requests;
the operator performs separately authorized tools. Do not start new paid work,
connect accounts, switch providers or alter the human review schedule from this
prompt alone.
