# Campaign calendar

Build from one source and a named audience progression. Give each calendar slot a date/timezone, audience, channel, angle, purpose, CTA and asset reference. Vary the substance across video, written social, email, blog, changelog and popup. Avoid unsupported case studies and repeated announcements. Keep slot intent separate from the final asset binding so a date edit requires calendar review without redrafting unchanged copy.

Return concrete draft material or a specific review finding. Mark missing source, tool access, and uninspected output as gaps. Use only the selected product and voice context. Every new rendition needs its own version, hash, and human review.
