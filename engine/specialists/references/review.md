# Independent delivery review

Read the actual artifact, selected source excerpts and voice examples. Inspect media output when the host can display it. Report pass, fail or not_tested for each applicable rubric, with evidence. A successful hash check establishes bytes only. Recommend review, changes or a hold. Do not substitute a quality score for Gabe's or Reviewer's decision.

For a disputed visual finding, name the artifact hash and exact frame or timestamp. Check a fresh decode from that file before marking the finding blocking. Keep displayed-image interpretation separate from decoded evidence and correct findings that the evidence contradicts.

Return concrete draft material or a specific review finding. Mark missing source, tool access, and uninspected output as gaps. Use only the selected product and voice context. Every new rendition needs its own version, hash, and human review.
