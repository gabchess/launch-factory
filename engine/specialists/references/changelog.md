# Changelog

Name what changed, who can use it and the first useful action. Preserve rollout, access and limitation qualifiers. Prefer a concrete behavior over launch hype. If source evidence cannot establish availability, state the gap. Return headline, concise change text and source-linked details.

Return concrete draft material or a specific review finding. Mark missing source, tool access, and uninspected output as gaps. Use only the selected product and voice context. Every new rendition needs its own version, hash, and human review.

Use the original [changelog production prompt](../channel-production/prompts/changelog.md) when producing the entry. The [channel preparation guide](../channel-production/README.md) defines the work packet and review boundary.
