# When a capability is missing

Without Python or FFmpeg, prepare the source claims and copy in the AI host. Mark rendering and verification unexecuted. Give the operator the missing tool and the next command from [the reference](../../../docs/REFERENCE.md).

Without native delegation, read the chosen specialist's protocol and perform it inline. Report that fallback. Without the human Claims Lock, stop before drafting. A partial draft must never be presented as a completed package.
