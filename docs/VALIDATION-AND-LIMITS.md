# Validation and limits

[The v2 audit](V2-AUDIT.md) records executed checks. [The input reference](REFERENCE.md) gives the accepted format and limits.

Tests cover input bounds, exact quote matching, changed sources, Claims Lock, real media rendering, package hashes, and failed-build cleanup. Browser checks cover the generated review pages and interactive previews.

Source references require human judgment: a valid quote does not establish that an AI paraphrase is accurate. The example is a self-release rehearsal with no approval. Native host delegation, provider execution, authenticated decisions, and publication are not established by these tests.
