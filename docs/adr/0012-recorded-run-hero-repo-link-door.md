# ADR 0012: a recorded workflow and reusable repository

Date: 2026-09-07. Status: historical; updated by [ADR 0020](0020-v2-local-package-builder.md).

## Decision

Show a recorded run alongside the source repository. The recording should make the inputs, outputs and human review steps visible. The repository provides the installation instructions and reusable workflow.

## Consequences

A recording demonstrates the specific run it shows. Host support and setup still need their own checks. Current installation and release downloads are described in the root README.
