# Social posts

## Reader

A sales manager scrolling a feed. They give a post about two seconds, so each line must make sense on its own.

## Parts

Write three post options for the same change. Each option has these parts in this order, one line each.

1. Problem. The pain the reader knows.
2. Change. What is new, in plain words.
3. Proof. One number or example, labelled with where it comes from.
4. Status. Whether it is released, in beta or planned.

No link, no hashtags and no emoji in the post text. Put a source marker such as [1] after the proof line and after any other claim.

## Length

Each option is exactly 4 lines and 80 to 280 characters, markers not counted.

## Sources

Mark each claim with [1], [2] and so on. After the three options, add one "Sources" list with an entry per marker. Each entry is the link the user gave, or "pasted text" when the user pasted it in. Every link the user gave appears in the list, or appears as "not used, because <reason>". Claims you could not trace to any source go under a "Not traced" heading after the list, and stay out of the posts. The text is handed back for a person to post by hand. Nothing is posted.
