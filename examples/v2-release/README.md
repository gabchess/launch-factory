# Launch Factory v2 example

This rehearsal uses Launch Factory's own release notes and a recorded documentation walkthrough. The assets are real files. No human approval is claimed, and nothing is published or scheduled.

The copy was drafted by the Codex host from the quoted sources. `release.json` keeps the drafts and claim references together. Re-run with `./run.sh examples/v2-release --example --out runs/v2-example`.

Replace the example's sources, footage and drafts for your own release. A normal build needs the human Claims Lock described in the root README.
